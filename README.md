# Steamish — Game Discovery

A Steam-inspired game catalogue and content-based recommender. It stores game metadata and reviews, not game files.

## Run on Windows without Docker

### 1. Configure PostgreSQL

Install PostgreSQL and enable pgvector. Create the database if it does not exist:

```sql
CREATE DATABASE game_catalog;
```

Connect to it in SQL Shell and run:

```sql
\c game_catalog
CREATE EXTENSION IF NOT EXISTS vector;
```

Copy `.env.example` to `.env`, then replace `YOUR_POSTGRES_PASSWORD` with the password for your PostgreSQL `postgres` user. Keep `.env` private.

### 2. Install Python packages

From this folder in VS Code PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Initialize the catalogue

```powershell
python -m backend.init_db
```

This seeds 53 games, their embeddings, demo users and fictional sample reviews. The first run may download the sentence-transformers model.

### 4. Start the backend

In Terminal 1:

```powershell
python -m backend.server
```

Leave it running; it listens on `127.0.0.1:8765`.

### 5. Start the frontend

Open Terminal 2 in the same project folder, activate the environment if needed, and run:

```powershell
.\.venv\Scripts\Activate.ps1
streamlit run frontend/app.py
```

Open the local URL printed by Streamlit, usually `http://localhost:8501`.

## Features

- Search/filter the seeded game catalogue.
- Game details and review submission.
- Content-based recommendations using 384-dimensional embeddings and pgvector.
- Add games to and browse the demo library.
- Atomic demo-credit transfers illustrating database transactions.
- Redis is optional; the application continues without it.

## Troubleshooting

- `password authentication failed`: update `DATABASE_URL` in `.env` with your actual PostgreSQL password.
- `connection refused` on port 5432: check that the PostgreSQL Windows service is running and confirm `SHOW port;` in psql.
- Backend unavailable in the UI: keep `python -m backend.server` running in Terminal 1.
- `vector` extension missing: install a pgvector build compatible with your PostgreSQL version, then run `CREATE EXTENSION vector;` inside `game_catalog`.
- If recommendations fail, inspect the backend terminal for the database error. Game embeddings must have been generated by `python -m backend.init_db`.

## Architecture notes

Streamlit calls a Python TCP service using 4-byte big-endian length-prefixed JSON. PostgreSQL is the source of truth; pgvector stores embeddings. Redis is an optional cache. User-submitted reviews and library writes use database transactions; demo-credit transfers lock rows and debit/credit atomically. Seed reviews are fictional and labelled as such.

This is a learning-project starter, not a production storefront. Production use needs authentication, authorization, rate limiting, moderation, migrations, monitoring, and backups.
